# 第三方代码与硬件参考资料

这里集中保存开发 Panelet 所需的第三方代码、字体和硬件资料。**它们不自动适用仓库根目录
针对 Panelet 自有代码的许可证**；各文件原有版权、许可和使用条件继续有效。

| 目录 | 内容 | 权利范围 |
|---|---|---|
| `wiki/` | NOTE4C 官方说明的固定版本快照与图片 | 保留原版权；Wiki 的 `alr` 声明不等于开源许可 |
| `datasheets/` | 厂商器件资料、原理图和控制器 Proposal | 保留原文件与通知，具体共享权限按每份材料记录 |
| `youn-ink-fourcolor-firmware/` | 参考固件源码 | 顶层 MIT；嵌套组件按各自条款，包括部分 Espressif 产品范围限制 |
| `vendor/` | 精确版本依赖及受控补丁 | 保留上游许可、版权和本地修改说明 |
| `fonts/` | GNU Unifont 原始数据与通知 | 按字体自身双许可及嵌入例外处理，不能套用 Rust 代码许可 |

[来源清单](SOURCES.md)记录 URL、版本、获取日期、修改和哈希。权限未确认是需要补充的
逐项信息，不自动等于必须删除，也不表示署名后即可任意再分发。引用、完整副本的镜像
与分发含第三方代码的制品，应分别按适用条款判断。

保留参考资料是为了使硬件实现依据可以追溯，不表示 Panelet 拥有厂商文档版权，也不表示
厂商为本项目背书。设备凭据、个人数据和 Flash 备份不属于这里的参考资料。
