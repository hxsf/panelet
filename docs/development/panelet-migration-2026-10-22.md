# Panelet 更名与文档迁移验证（2026-10-22）

本次将平台命名为 Panelet，更新源码包、固件与 Studio 名称，分离设备文档和 OS 契约，
并补齐仓库原有的 MIT OR Apache-2.0 许可证与第三方通知。当前仍只支持 NOTE4C。
本记录是软件与构建证据，没有连接、刷写或重新验收真实设备。

随后维护者选择项目自有代码使用 MPL-2.0、小组件示例使用 MIT。当前许可范围以
[许可证与分发范围](licensing.md)为准；下方构建字节数和测试数量属于更名阶段的记录，
不冒充随后许可与示例打包调整的最新结果。后续检查见[首次公开许可验证](mpl-release-2026-10-22.md)。

## 改动边界

- 固件入口为 `app/os` / `panelet-os`，原生编辑器为 `panelet-studio`，共享 crate 使用 `panelet-*`。
- 旧包格式、Rune ABI、存储 marker、凭据派生、widget ID 和刷写确认变量保留，见[兼容性说明](naming-and-compatibility.md)。
- 设备资料与历史日志在 `docs/devices/<device>/`，系统契约在 `docs/os/`；历史测量值和制品名未改成新固件证据。
- 新设备接口、显示 profile、平台适配层与独立编译器/VM 是[后续规划](architecture.md)，没有建立空 crate 冒充已实现。
- 更新了旧诊断操作说明与启动提示，按当前 normal/diagnostic 路由解释按键；没有改变输入路由逻辑。
- 根双许可和固定版本 Rune、Unifont 通知补齐。八份硬件研究资料在初次整理时曾移出跟踪；随后按维护者要求恢复，保留原版权、来源与逐项权限记录，见[参考资料范围](licensing.md#硬件参考资料的保留与权利范围)。统一过滤历史的候选方案已撤回，原始历史不改写。
