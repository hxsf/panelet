# 设备支持

Panelet 的第一款设备是 NOTE4C，后续计划支持 NOTE4 和其他带屏幕的开发板。项目更名不代表固件已经能运行在所有设备上。

| 设备 | 状态 | 显示与边界 | 入口 |
|---|---|---|---|
| ZECTRIX NOTE4C Devkit，PCB V1.0 | 已有适配与限定范围的实机记录 | 4.2 英寸、400 × 300、SSD2683 四色；各功能验证范围见设备页，最新软件能力不等于全部已上板 | [NOTE4C](note4c/README.md) |
| NOTE4 黑白屏 | 规划中，尚未支持 | 控制器、接线、显示协议和恢复条件需独立确认，不兼容套用 NOTE4C 固件 | [NOTE4 接入清单](note4/README.md) |
| 其他带屏幕开发板 | 尚无适配 | 按具体型号、PCB 和显示变体建立独立档案 | [添加新硬件](../development/adding-device.md) |

设备目录保存安装、恢复、硬件限制和实机证据；通用小组件、管理协议和存储契约在 [`docs/os/`](../os/)。每次新增板卡或板卡 revision，都应明确哪些结论来自资料、主机测试、目标构建或实机观测。

本文的“已有适配”只覆盖日志声明的硬件与行为，不表示低功耗、所有外设或全部新软件功能均已验收。BLE、音频、NFC 不能因芯片或板卡具有相应能力而直接列为 Panelet 已支持功能。
