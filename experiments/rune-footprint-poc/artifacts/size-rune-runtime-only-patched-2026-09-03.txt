front-end API identifier appears under `note4c-rune-runtime-only-poc`,
`note4c-rune-abi-poc`, or `rune_runtime_only_footprint.rs`. However the final
map still proves the Rune monolith links front-end/index pieces, including:
- map line 52: `rune7compile7context...TraitContext...`;
- map line 56: `rune5query5query...Query...`;
- map line 66: `rune3ast...parse6parser6Parser...`;
- map lines 3917 onward: `rune8indexing...`.

Therefore this is a precompiled-Unit consumer at the application level, but
not a parser/compiler/indexer-free Rune runtime binary.
